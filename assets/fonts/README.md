# Home profile font

`Fredoka-Variable.ttf` is the unmodified Fredoka variable font from the official Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/fredoka

The accompanying `OFL-Fredoka.txt` contains the SIL Open Font License and copyright notice, and is bundled with the game. The font is loaded locally by Flutter; no runtime font download or additional package is used. Only the enlarged Home profile greeting and username use this font.
